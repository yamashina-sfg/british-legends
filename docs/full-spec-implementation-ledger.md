# British Legends 全仕様実装台帳

## 正本と変換方針

- ゲームエンジンの正本: `/Downloads/仕様書/` のPowerPoint 18冊・Excel 2冊、および開発仕様PDF 48ページ。
- IPの正本: British Legends。元資料固有の名称・画像・世界設定は持ち込まない。
- 変更仕様を優先: `仕様修正`、`ステータス仕様変更`、各資料の更新日が新しい記述を旧記述より優先する。
- Web版ではUnity/PlayFab/Photon固有実装を、同じプレイヤー体験を満たすWeb/PWA技術へ置き換える。

## 依存順ロードマップ

1. 共通基盤: マスターデータ、ローカライズ、保存版、フラッグ、通貨、取得履歴。
2. キャラクター: 6能力の完全計算、仮振分/確定、結婚、星神、スキン。
3. フィールド戦闘: リアルタイムAC、自動攻撃、敵AI、属性、床ドロップ。
4. 所持品: 6部位装備、制作、スキル、バフ、5枠クイックスロット。
5. 成長コンテンツ: ペット、アルバム、図鑑達成効果、釣り。
6. エンドコンテンツ: 闘技場Wave、記録、ランキング。
7. 運営基盤: アカウント同期、バージョン更新、商品・購入ログ、サウンド全接続。

## 完了判定

- 資料中の各機能に、実装コード・画面・セーブ項目・テストの対応先がある。
- 旧セーブを削除せず、自動移行できる。
- スマホ横・スマホ縦・PCで主要フローが進行不能にならない。
- 課金は実決済を勝手に有効化せず、商品台帳・購入状態・UIを先に実装し、決済接続は明示承認後に行う。
