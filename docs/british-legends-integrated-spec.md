# British Legends 統合ゲーム仕様書

## 1. 文書目的

本書は、提供されたスマートフォンRPG仕様書群をゲームエンジンの正本として、既存Web RPG「British Legends」へ統合するための実装基準を定める。IP（名称、世界、物語、登場人物、画像、音声）はBritish Legendsを使用し、数値規則、成長、画面遷移、装備、戦闘、ペット等は元仕様書に従う。元資料の固有IPや画像を転用せず、同じ機能をBritish Legendsの文脈へ翻訳する。

### 1.1 優先順位

1. ゲームエンジンの挙動は、提供仕様書の記述と計算式を優先する。
2. 世界観・固有名詞・キャラクター表現はBritish Legendsを優先する。
3. 既存実装と仕様書が衝突する場合、セーブ移行を用意したうえで仕様書へ寄せる。
4. 資料間で衝突する場合は「ステータス仕様変更」など変更仕様を優先する。

対象はスマートフォン横画面を主軸とするレスポンシブWeb/PWA。PCでは同一機能をワイド表示する。

## 2. コア体験

1. Bibliotheca Lodgeで編成、装備、回復、図鑑を整える。
2. 文学作品世界を選択し、ダンジョンを探索する。
3. ターン制戦闘で怪異を倒し、素材・写本断片・装備を獲得する。
4. 仲間、装備、伝承研究、写本アルバムを成長させる。
5. ボスを倒して作品を修復し、次の文学世界を解放する。

## 3. 画面・操作仕様

- 基準画面: スマートフォン横向き。最小タップ領域44px。
- 主要メニュー: ロビー、パーティ、ストア、素材、図鑑、設定。
- 横向きでは下部メニューを常時操作可能にし、セーフエリアを考慮する。
- 縦向きでも進行不能にせず、1カラムへ再配置する。
- マウスホバー専用操作は禁止し、タップ・キーボードの双方で操作可能にする。

## 5. 伝承研究

- 敵IDごとに累計討伐数を保存する。
- Rank I（1体）: その敵のEXP +5%。
- Rank II（5体）: その敵のGold +10%。
- Rank III（15体）: その敵の素材ドロップ率 +5ポイント。
- 図鑑には討伐数、現在Rank、次Rankまでの残数を表示する。

## 5A. キャラクター生成・成長（エンジン正本）

- プレイヤーはBritish Legends世界では「修復者」と呼ぶ。名前とヘッド外見を登録する。
- 身体素質は元仕様の婚姻女神選択を、Bibliothecaの司書による選定として表現する。機能は同一で、IP表現だけを置き換える。
- 英雄（Beowulf、Hamlet等）の固有基礎値は、元仕様にある振分不可の固定・実績能力として扱う。
- 能力値は ATK、INT、DEF、MDEF、SPD、LUK の6種。HP/MPは派生値として別表示する。
- Lv1の未使用レベルポイントは0。1レベル上昇ごとに3ポイントを得る。
- 振分上限は各能力99。婚姻相当の周回を1回行うごとに上限を10増やす。
- レベルアップ時はHP/MPを最大まで全回復し、Level Up演出を表示する。
- 移動速度は `8 + SPD / 300`。行動ゲージ上限は300、毎秒の増加量は `199 + SPD`。
- LUKによるドロップ倍率は `1 + min(LUK, 3600) / 360`（最大11倍ではなく、資料記載の基礎1を含む式を採用）。
- 会心率は `clamp((攻撃側LUK - 防御側LUK) / 1500, 0, 1)`、回避率は `clamp((防御側LUK - 攻撃側LUK) / 1500, 0, 0.95)`。0.1%単位で切り捨てる。
- 物理基礎ダメージは `((ATK + INT / 10) × 11) × 乱数(0.85〜1.15) × 属性倍率 - DEF × 7`。
- 魔法基礎ダメージは `((INT + ATK / 10) × 11) × 乱数(0.85〜1.15) × 属性倍率 - MDEF × 7`。
- 会心倍率は1.5、有利属性倍率は1.2。不利属性による減衰は行わない。
- 死亡時はGoldの10%（端数切り捨て）を失い、HP最大で復帰する。

## 6. 写本アルバム

### 6.1 断片獲得

- 宝箱、ボス、記憶イベントから一度だけ獲得する。
- 断片IDはセーブの `storyFragments` に保存する。
- 作品ごとに4断片を基本セットとする。

### 6.2 復元率

- 作品別復元率 = 獲得済み断片数 / 設定断片数。
- 図鑑「断片」タブで、断片名、入手状態、作品別復元率を表示する。
- 未獲得断片は名称を伏せ、入手ヒントだけを表示する。

### 6.3 Bibliothecaの祝福

全作品を横断したユニーク断片数により、味方全員へ累積適用する。

| 断片数 | 永続効果 |
| --- | --- |
| 3 | 最大HP +10 |
| 6 | ATK +2 |
| 9 | DEF +2 |
| 12 | 最大HP +20、最大MP +5 |

## 7. セーブ互換性

- 新規項目は必ず既定値を補完し、既存セーブを削除しない。
- `defeatCounts` がない旧セーブは空オブジェクトとして読み込む。
- 写本アルバムは既存の `storyFragments` をそのまま使用する。
- `equipmentLevels` がない旧セーブは空オブジェクトとして読み込む。

### 7.1 鍛造・装備強化

- 所持装備はBibliotheca Storeの「鍛造」タブへ表示する。
- 強化上限は+5。失敗・破壊・強化値低下は発生しない。
- 強化にはGoldと装備作品に対応する素材を消費する。
- 必要素材数は+1で1個、最大強化時は5個。
- 1段階ごとに装備固有ステータスを10%強化し、端数は切り上げる。
- 強化値は装備ID単位で保存し、装着者を変更しても維持する。

### 7.2 クイックスロット

- 戦闘用消費アイテムを4枠へ登録できる。
- Storeの「道具」タブで枠を選択し、登録・解除する。
- 同じアイテムを複数枠へ重複登録しない。再登録時は古い枠を空ける。
- 戦闘のコマンド画面に4枠を常時表示し、1タップで使用する。
- 使用すると通常の1行動を消費し、所持数を1減らす。
- 蘇生薬は戦闘不能者がいる場合のみ使用可能。
- 旧セーブは既定の4アイテムを自動登録する。
